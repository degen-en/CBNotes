Program for making notes.

"Console based notes"

Hopefully i'll upgrade it

Hope you like it




'mk name' makes note adding current note as target
'cat name' reads the note
'cd name' moves to note
'cg name' rewrites note

'cgs name number' changes style of note name (32 - green, 33 - yellow, 34 - blue, 35 - purple etc.)
'fmk name target1 target2 :d' creates note with targets
'gcd name' moves through all notes
'at name target' adds target
'rmnote name' removes note

"." reads as the current note
